How can I play a /dev/dvb/adapter0/dvr0 DVB stream in Ubuntu?

To play a DVB stream from /dev/dvb/adapter0/dvr0 on Ubuntu, you can use a combination of tools like VLC, FFmpeg, or TVHeadend. I’ll show you how to stream and play the DVB content directly from the device.

Prerequisites:

Ensure your DVB hardware is properly installed and recognized. This means you should have the appropriate drivers for your DVB device (like dvbsky, dib0700, or others depending on your hardware).

The device should appear under /dev/dvb/adapter0/, with various files like frontend0, demux0, dvr0, and net0.

Option 1: Playing DVB stream directly with VLC

VLC has the ability to play DVB streams directly from the device. This is one of the easiest methods.

1. Install VLC (if it's not already installed):
sudo apt update
sudo apt install vlc

2. Open VLC and select DVB stream source:

You can play the DVB stream directly using VLC.

Open VLC (via GUI or command line).

From the menu, go to Media > Open Capture Device.

In the Capture Device tab:

Capture mode: Select DTV/Analog TV.

Device name: Set it to /dev/dvb/adapter0/dvr0 (this is your DVB input stream device).

Optionally, set up video and audio input preferences if you know the parameters (e.g., frequency, modulation, etc.), or you can let VLC try to auto-detect them.

If you're comfortable with the command line, you can also start VLC with a command like:

vlc dvb-t:// :dvb-frequency=474000000 :dvb-bandwidth=8


Replace 474000000 with the actual frequency of your DVB channel (in Hz).

You can specify dvb-t://, dvb-s:// for terrestrial or satellite, respectively.

Once you enter the stream details, you should be able to see the live DVB stream in VLC.

Option 2: Play DVB Stream Using FFmpeg

You can use FFmpeg to decode and play a DVB stream from /dev/dvb/adapter0/dvr0. If you want more control over encoding or streaming, FFmpeg is a great tool.

1. Install FFmpeg (if it's not already installed):
sudo apt update
sudo apt install ffmpeg

2. Capture and play the DVB stream with FFmpeg:

Run the following command to capture the stream from /dev/dvb/adapter0/dvr0 and play it using FFmpeg. You can choose to convert it into a playable format like MPEG-TS or HLS, but here, we’ll play it directly in the terminal.

ffmpeg -i /dev/dvb/adapter0/dvr0 -c copy -f mpegts - | vlc -


-i /dev/dvb/adapter0/dvr0: Input the DVB stream.

-c copy: Copy the video and audio streams without re-encoding.

-f mpegts: Set the output format to MPEG Transport Stream (the format commonly used for DVB).

The | vlc - command pipes the output to VLC for playback.

Optionally, you can output to a file:
ffmpeg -i /dev/dvb/adapter0/dvr0 -c copy -f mpegts output.ts


This command will save the output as a .ts file, which you can later play or stream.

If you want to stream the DVB content directly to HLS for easy access from web browsers or media players, you can use FFmpeg for this. Here's an example:

ffmpeg -i /dev/dvb/adapter0/dvr0 -c:v libx264 -c:a aac -f hls -hls_time 10 -hls_list_size 6 -hls_segment_filename "/var/www/html/stream%03d.ts" /var/www/html/stream.m3u8


-i /dev/dvb/adapter0/dvr0: Input from the DVB device.

-c:v libx264: Encode the video in H.264 format.

-c:a aac: Encode the audio in AAC format.

-f hls: Output as HLS.

-hls_time 10: Segment duration (in seconds).

-hls_list_size 6: Number of segments in the playlist.

-hls_segment_filename: Format for the segment files.

/var/www/html/stream.m3u8: The resulting HLS playlist file.

Summary of Options:

VLC is the easiest way to play a DVB stream directly from the device (/dev/dvb/adapter0/dvr0).

FFmpeg allows you to capture and stream DVB content to different formats (e.g., HLS, MPEG-TS).

TVHeadend provides a more robust solution for managing DVB sources and streaming via HTTP, RTSP, and HLS.

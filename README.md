# HauppaugeChromecast

Streaming TV application that uses the Hauppaugee [WinTV SoloHD](https://www.hauppauge.co.uk/site/products/data_solohd.html) TV tuner and [Google Chromecast](https://developers.google.com/cast) to stream live TV.
